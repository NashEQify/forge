# Navigation: _protocols/

## What lives here?

**Persona-level protocols** — required mechanics loaded by every (or
many) reviewer and council persona. On dispatch Buddy names them by
path for the seat to read: persona definition + board protocol +
checked scope + reviewer base (`skills/_protocols/dispatch-template.md`
§Aborted seat, the standard shape).

**Hierarchy:**
1. `reviewer-base.md` — applies to ALL review agents (Spec / Code /
   UX board).
2. `<board>-reviewer-protocol.md` — board-specific rules (spec / code
   / ux).
3. `reviewer-checked-scope.md` — the required section
   before the findings.
4. `code-reviewer-base-extended.md` — extended conventions for the
   Code Board.

Boundary against `skills/_protocols/`: those are skill-level mechanics
(cross-loaded by skills). The protocols here are persona-level
(cross-loaded on persona dispatch).
