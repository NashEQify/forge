# Navigation: buddy/

## What lives here?

**Buddy as orchestrator** — tool-neutral definition. Adapters
(the Claude Code wrapper in the repo-root `CLAUDE.md`, `AGENTS.md` for Codex
and OpenCode) load these files at boot.

**Three-tier model** (matches the repo-wide tier convention):
- **Tier 0 (invariants):** `framework/invariants.md`; the repo-root `CLAUDE.md` +
  `AGENTS.md` add the forge repository's own rules. Never override.
- **Tier 1 (operational):** the files here. Who Buddy is + how Buddy
  runs.
- **Tier 2 (detail):** extracted into `context-rules.md`.

## Moments

Lookup from a moment to the unit that owns its rule. What acts at the moment is the carrier named (the standing
block in the start text, a step text, a role body, a dispatch, a check); this map is for an author or a lookup, not
a trigger.

| Moment | Owner unit | Carrier at the moment |
|---|---|---|
| Work of more than one piece arrives; where each piece runs | `delegation.md` §Vehicle choice | the step text naming its executor |
| An agent call and its model | `framework/models.md` §Naming the model | standing block "Agent call"; `skills/_protocols/role-dispatch.md` step 4 |
| Briefing a session, coordinating, integrating, a second writer | `coordinating-sessions.md`, `concurrent-writers.md` | the paragraph in `operational.md` §Coordinating sessions and writers |
| A further round: fix pass, re-review, extension | `delegation.md` §Cumulative effort; `architecture-comprehension.md` §B | the review step texts in an engine run; the brief's effort budget |
| Choosing or waiving a review; about to ask the user | `multi-perspective.md` | the review step texts; standing block "Decision to the user" |
| Scoping outcomes, comparing structures, adding machinery | `architecture-comprehension.md` | none (on demand) |
| Adopting a return | `skills/return_summary/SKILL.md` | the return's adoption lines |
| Ending a turn with own background work | `background-wait.md` | standing block "Turn end with own background work" |
| Receiving a wait report | `background-wait.md` §Receiving a wait report | from a session: `coordinating-sessions.md` §One reading place; from an agent: none (on demand), the dispatch's "No return while its own work runs" prevents it |
| Proposing a simpler mechanism; a pattern-replacing MCA dispatch | `multi-perspective.md` | none (on demand) |
| Writing or changing a rule | `skills/_protocols/instruction-form.md` | the commit checks' refusal text |
| A required skill the host cannot invoke | `skill-fallback.md` | none (on demand) |
