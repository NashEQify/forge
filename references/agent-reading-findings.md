# Agent reading findings

What was measured about how an agent reads its instructions, with the count, the method, where it was measured and
what would change it. Lookup material: it holds no rule. The rules that rest on an entry cite it by number
(`skills/_protocols/instruction-form.md`, `framework/skill-anatomy.md`).

Common to every entry unless it says otherwise. **Measured:** 2026-11-14, over the transcripts of one machine from
2026-10-31 on: Claude Code sessions in a checkout (about 51 booted main sessions of one framework repository and one
consumer project) and their sub-agents. **Models:** the sessions' own, mostly two Claude models that the data cannot
separate from session role (E12). **Not measured:** Codex, plugin-copy sessions, other machines. A count is n of m.
**What would change it:** a repeat of the measurement after a model change, a host release that changes hooks,
compaction or skill loading, or a different setup; the entry is then updated with its new count and date.

| # | Finding | Count | Method | Limit |
|---|---|---|---|---|
| E1 | A "read X when Y" paragraph loaded at session start rarely produces the read at its moment. | The named unit was in context at 12 of 207 moments when no other text named it, 200 of 505 when one did; without the most frequent moment (turn end with background work) 11 of 69. | transcript: moment detectors, reads before the moment | the moments are those a script can detect |
| E2 | A rule sentence loaded at start does not reliably produce its act later when nothing else names the act. | Cue-free acts with a cost: 29 of 120, 70 of 296, 5 of 20. In one session and one rule it fell with age: 4 of 4, 8 of 40, 2 of 99, then 10 of 10 after the host re-delivered the text. Standing prohibitions held at 97 to 100% with no baseline without the sentence. | transcript: act per occurrence | one session for the fade; prohibitions have no control group |
| E3 | Text that arrives with the work is read. | Units named in a dispatch read in 562 of 686 call-unit pairs (737 of 939 over all groups); named in a session brief 52 of 67; a role file named in the prompt 59 of 62. | transcript: reads after the dispatch or brief | read is not applied (E9) |
| E4 | A named path is still a hop, and hops lose. | A unit path printed by the workflow engine read afterwards in 0 of 7 and 6 of 17 session-path pairs; protocols named in the dispatch 15 of 27 and 34 of 34, listed only in the role file 8 of 38 and 8 of 25. | transcript | two groups that differ widely |
| E5 | A required element of an artifact gets filled when the author's own earlier artifact of the kind is in context. | One coordinator over three days: session briefs carried the acceptance block 23 of 23, the model line 22, the effort budget 22; 43 of 47 had an earlier brief by the same session in context. Against it: 11 of 18 fix briefs lack sections; the consumer has 0 of 6 briefs with the block. | repository records and transcripts | measures the session's own previous output, lost at compaction, not a template or a predecessor file |
| E6 | A rule stated in context is planned for in a single reading; with no rule it is not. | Rule stated: 8 of 8; no rule: 0 of 4. Live: a pointer not followed in 0 of 29 cases without another cue; with the unit in context the act followed on 138 of 145 agent calls. | fresh-context readings (one model, two per cell); transcript for the live counts | a reading cannot reproduce age, compaction or session role |
| E7 | After compaction, what the host delivers is back; what the agent is asked to reread mostly is not. | Hook text after 16 of 16 compactions; of eleven start-loaded units, five were reread after 0 of 16, the core process unit after 1 of 16, the most-reread after 6 of 16. | transcript: reads after each compaction boundary | Claude Code only |
| E8 | Limits stand where they are not read, duties where they are. | One recorded fix loop ran 17 full test runs inside an engine run whose step text had the duties and not the limits. | transcript and the loop's records | one loop; a pattern found by audit, not a rate |
| E9 | Read is not applied; form decides. | A verifier with an unconditional text: wrong verdict in 2 of 2 readings; with a condition list and a named output section: right in 4 of 4. | fresh-context readings | two and four readings |
| E10 | An agent's own previous output predicts its next. | A required closing line in 221 of 237 turns after a turn that had it, 16 of 1,258 after one that had not; the model named on 236 of 247 agent calls when the previous call named it. | transcript | lost at compaction |
| E11 | The room is not where it was assumed. | Explanation, history and delimitation together 7.7% of 287,224 measured bytes; in the start-loaded set 31% (20,763 of 66,033 bytes) serves a later moment. | two classifiers over the units | the classifiers agreed on 55% and 32% of explanation bytes and on none of the delimitation bytes |
| E12 | Model and session role outweigh every form factor in the data, and cannot be separated in it. | A required closing line on 215 of 232 turns of one model against 29 of 1,244 of another; every session of the first was human-driven. Turns begun by a notification or a brief score lowest on every output element. | transcript | confounded by design of the data |
| E13 | Host start text: each start handler of the host has its own budget. | Claude Code 2.1.302 (command line, headless and interactive): three start handlers of about 9,500 characters each arrived whole; one of about 11,600 went to a file with a 2,000-character preview the model did not open; 260 lines arrived whole. | scratch hooks, transcript and the model's echo | the desktop app's entrypoint not measured |
| E14 | Host events that are not tool calls deliver before the model acts. | Claude Code 2.1.302: text on an incoming message arrived before the answer and also on a background task's completion notice; text at a sub-agent's start reached only that sub-agent; text at a turn end made the model take one more turn and reply about it. | scratch hooks, one run per case | no run on Codex or the desktop app; a message from another session not probed |
