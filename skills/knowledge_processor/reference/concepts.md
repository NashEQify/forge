# Continuity concepts

The executable authority is `../SKILL.md`; this file explains it rather than
establishing another lifecycle. Placement follows ownership and retrieval needs,
not psychological facets or maturity stages. Summaries expose minimal implications
and link to responsible detail/evidence. More stored detail need not mean more
boot context. Around 200 lines is a review signal, never an eviction trigger.

## Entropy audit compatibility

“Entropy audit” means a proportionate review of the currently touched topic's
validity, pending recovery, navigation and known dependent summaries under the
canonical lifecycle. Wider housekeeping is explicit or already required by the
project. No global history/backlog scan, age-based deletion, mandatory revalidation
interview, automatic SSH verification or background scheduler is introduced.
Selected software workflows retain their own exact-state/plan validation.

## Continuation and context limits

A session buffer is optional existing working state, not a second knowledge owner.
Same-cycle maintenance does not depend on a SessionEnd hook. Preserve unresolved
items until actually reconciled; use scoped pending recovery for interrupted
publication. A statement that a topic is “unloaded” cannot remove it from the model's
context window. Read the file again when fresh state is needed after resume or change.
